# 贪吃蛇 🐍

一个**单文件、零依赖**的贪吃蛇小游戏，纯 HTML + JavaScript。

## 玩法
- 🐍 **100 × 100 超大棋盘**，画布自适应窗口，手机也能全屏玩
- ⚡ **越吃越快**：蛇每长一节提速，最快 40ms/格
- 🎮 **多种操作**：方向键 / WASD、触屏滑动、手机端虚拟方向键
- ⏸ **暂停/继续**：空格、P 或 Esc；死亡后空格/回车重开
- 🏆 **最高分**：localStorage 永久保存
- 🔊 吃食物和死亡都有 WebAudio 音效
